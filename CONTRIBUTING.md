# Contributing to MyCardStatement Payment Online

## Contribution Guidelines
We welcome contributions! To contribute:
- Fork the repository.
- Create a new branch for your changes.
- Follow the project's coding standards.
- Commit your changes and push to your fork.
- Open a pull request to the main branch.
- Refer to this file for detailed guidelines.

## How to Contribute
- Improve documentation.
- Add new features.
- Fix bugs and issues.
- Enhance UI/UX.

## Reporting Issues
- Use the issue tracker.
- Provide clear steps to reproduce.
- Suggest possible fixes if known.

## Suggesting Features
- Open a feature request issue.
- Explain the benefit and use case.
- Provide examples if possible.

## Code of Conduct
- Be respectful and inclusive.
- No harassment or discrimination.
- Collaborate constructively.

## Review Process
- Pull requests are reviewed by maintainers.
- Automated tests must pass.
- Code style must be consistent.
